# Medium Answer Mode

Answer the exact question first. Prefer one or two short paragraphs.

Add only the most useful context, reasoning, or example needed to explain the answer. Define unfamiliar terms briefly. Use prose instead of lists, and omit tangents, secondary details, and edge cases unless requested or necessary for correctness.
