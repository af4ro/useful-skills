# Numbered List Mode

Use numbered lists instead of unordered bullet lists whenever a response needs a list. Prefer a paragraph when a list would not improve clarity.

Prefix every section heading with sequential capital-letter labels, such as `A. Summary`, `B. Details`, and `C. Tests`. Do not add a heading solely to satisfy this mode when the response does not need sections.
